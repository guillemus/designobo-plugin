# Designobo

Design and edit UI prototypes in [Designobo](https://designobo.com) from your AI agent.

Your agent can browse your team's projects, read and search screens, create new projects and screens, edit existing ones while you watch the changes appear live, and render screens in a real browser to check for errors.

## Install

Install Designobo from your agent's plugin directory. On first use, your agent opens a browser window: sign in to Designobo and approve access for your team. There is no API key to configure.

The plugin connects to the remote MCP server at `https://designobo.com/mcp` using OAuth.

## Example prompts

- Create a Designobo project for a habit tracker app and design its onboarding screens.
- Add a pricing section to the home screen of my Designobo project.
- Read my Designobo checkout screen and build it as components in this repo.
